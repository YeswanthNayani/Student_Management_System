# 🎓 Student Management System

A console-based **Student Management System** developed using **Core Java** and **Object-Oriented Programming (OOP)** principles. This application allows users to manage student records, process fee payments, calculate scholarships, and perform CRUD-like operations through a menu-driven interface.

---

## 📌 Features

- Register New Students
- Search Student by ID
- Pay Student Fee
- Calculate Scholarship
- Check Remaining Fee Balance
- Update Student Department
- Update Student Semester
- Delete Student Record
- View All Students
- Display Total Number of Students

---

## 📖 Functionality

### Register Student
Allows users to register a Regular or Scholarship student with details such as:
- Student ID
- Name
- Department
- Semester
- Fee Balance

### Pay Fee
Students can pay part or full fees. The system automatically updates the remaining fee balance.

### Scholarship Calculation
- Regular Student → Not eligible for scholarship.
- Scholarship Student → Receives a 50% scholarship.

### Student Management
Users can:
- Search students
- Update department
- Update semester
- Delete records
- View all registered students
